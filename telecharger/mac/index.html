Ensuite : installer, puis autoriser l'ouverture (une fois)

  1. Ouvrez Alixo-Mac.dmg et glissez Alixo dans le dossier Applications.
  2. Lancez Alixo depuis Applications. macOS affiche « Impossible d'ouvrir « Alixo », car Apple ne peut pas vérifier l'absence de logiciel malveillant » : cliquez sur Terminé (surtout pas sur « Placer dans la corbeille »).
  3. Ouvrez Réglages Système › Confidentialité et sécurité, descendez jusqu'à la partie Sécurité : à côté de « Alixo a été bloqué… », cliquez sur Ouvrir quand même, puis confirmez avec votre mot de passe ou Touch ID.

C'est tout : Alixo s'ouvre ensuite normalement. Sur macOS 13 ou 14, un clic droit sur Alixo › Ouvrir › Ouvrir suffit.

Pourquoi cet avertissement ?

Alixo n'est pas encore signé par Apple : cela demande une inscription payante au programme développeur Apple, que nous n'avons pas encore. L'application est exactement la même que sur Windows et sur le web, avec le même compte et les mêmes cours. L'avertissement est à lever une fois par version installée.

« Alixo est endommagé et ne peut pas être ouvert »

Ce message vient d'une version plus ancienne. Retéléchargez le .dmg ci-dessus, ou, dans le Terminal (Applications › Utilitaires), collez cette commande puis appuyez sur Entrée :

xattr -cr /Applications/Alixo.app

Mises à jour

Sur Mac, Alixo vous prévient quand une nouvelle version existe ; revenez alors sur cette page pour récupérer le nouveau .dmg et glissez Alixo dans Applications (vos cours sont conservés).
