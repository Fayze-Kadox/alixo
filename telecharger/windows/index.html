Ensuite : installer

  1. Ouvrez Alixo-Setup.exe depuis vos téléchargements.
  2. Windows SmartScreen peut afficher « Windows a protégé votre ordinateur » : c'est fréquent pour une application récente. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.
  3. Suivez l'installation : Alixo se lance tout seul à la fin, avec un raccourci sur le Bureau et dans le menu Démarrer.

Les mises à jour s'installent ensuite automatiquement au démarrage. Vous préférez ne rien installer ? Il existe une version portable.
